١. أقسام التقرير بالترتيب

  1. البيانات: اسم المريض والعمر والجنس والطول والوزن وسطح الجسم، والتاريخ، سبب الفحص، نوع الإيكو (عبر الصدر/المريء/جهد/مركّز)، ضغط الدم ومعدل القلب والنظم، جودة النوافذ.
  2. البطين الأيسر: الأبعاد، سماكة الجدران، الكتلة/النمط عند الحاجة، EF (والطريقة)، الحركة الجدارية، GLS إن وُجد.
  3. الوظيفة الانبساطية وضغط الامتلاء: الدرجة أو «طبيعية» أو «غير حاسمة» مع القياسات.
  4. البطين الأيمن: الحجم، الوظيفة (TAPSE وS′ وFAC)، السماكة.
  5. الأذينان: الحجم (LAVI، مساحة RA)، الحاجز بين الأذينين (PFO/ASD).
  6. الدسامات الأربعة: الشكل والحركة، الشدة بأرقام (تضيّق/قلس)، الآلية.
  7. الأبهر والشريان الرئوي: الأقطار.
  8. التامور: انصباب (الحجم والموضع) وعلامات السطام.
  9. الضغوط: IVC، RAP، PASP، ضغط الامتلاء.
  10. أخرى: كتل، خثرات، أجهزة، مقارنة بفحص سابق.
  11. الخلاصة (Impression) والتوصيات.

يُفضَّل ذكر الرقم مع الوصف (مثال: «ممال وسطي 42 ملم زئبق، تضيّق شديد») بدل الوصف وحده.

٣. قواعد أساسية

  • الدقة: ما لا يُقاس لا يُكتب بصيغة مؤكدة؛ يُكتب «لم يُقيَّم» أو «غير مرئي بوضوح».
  • الطريقة والمرجع: ذكر طريقة EF (Simpson/خطي)، الفهرسة (BSA)، والمرجعية (ASE/EACVI).
  • المقارنة: مع فحص سابق (تاريخه) مع ذكر التغيّر الحقيقي (انظر الأقسام الأخرى من هذا الفصل).
  • الإفصاح عن الحدود: نافذة صوتية ضعيفة، رجفان، تحفيز بطيني.
  • الربط بالسؤال السريري: أن تُجاب صراحةً سبب الطلب (مثلاً: «لا يوجد دليل على خثرة بالبطين»).
  • لغة مختصرة وجمل مفهومة، وتجنب الإسهاب والتناقض.

٤. بنية جملة النتيجة

النمط الجيد: [البنية] + [الصفة] + [الرقم] + [التفسير].

  • «البطين الأيسر متوسع بشكل خفيف (LVIDd 6.0 سم)، مع نقص تقلص عام شديد (EF 28% بطريقة Simpson).»
  • «الدسام الأبهري ثلاثي الشرف متكلس بحركة محدودة؛ سرعة ذروة 4.4 م/ث وممال وسطي 48 ملم زئبق وAVA 0.8 سم²: تضيّق أبهري شديد.»

٦. هل التغيّر حقيقي؟ (تقريبي)

لكل مقياس تفاوت طبيعي بين فحصين (متكرر أو بمراقب مختلف)، ويُعدّ التغيّر ذا معنى فقط إن تجاوزه:

القياسالتغيّر المعتبر تقريباً
EF≥ نحو 8–10 نقاط مئوية
أحجام البطين≥ نحو 15–20%
GLS≥ نحو 2–3 نقاط مئوية (أو > 15% نسبي)
قطر الجذر الأبهري≥ نحو 3 ملم بين فحصين بالتقنية نفسها
السرعة الأبهرية (AS)≥ نحو 0.3 م/ث
القاعدة: قارن بنفس المقياس والمنظر والتقنية (وبنفس الجهاز إن أمكن)، وأعد القياس القديم عند الشك.

٧. تحسين دقة قياساتك

  • بروتوكول ثابت لكل فحص (ترتيب المناظر والقياسات).
  • خذ 3 نبضات بالنظم المنتظم، و5–10 نبضات بالرجفان (أو نبضات ذات فاصل RR متقارب ويُحدَّد بـ«نبضة المؤشر»).
  • وثّق التوقيت من ECG وحدّد نهاية الانبساط/الانقباض بنفس القاعدة.
  • استخدم الظليل عند عدم وضوح الحدود؛ وTOE عند الحاجة.
  • سجّل الطريقة والمرجع بالتقرير (Simpson، خطي، BSA، مرجعية ASE...).
  • راجع الصور بعد الفحص قبل إصدار التقرير.

٨. حالة طبيعية

«بطين أيسر بأبعاد طبيعية (LVIDd [ ] سم) وسماكة جدران طبيعية، ووظيفة انقباضية طبيعية (EF [ ]%) بلا اضطراب حركة موضعي. وظيفة انبساطية طبيعية. أذينان طبيعيان. بطين أيمن بحجم ووظيفة طبيعيين (TAPSE [ ] ملم). الدسامات الأربعة طبيعية الشكل والحركة، قلس طفيف فيزيولوجي بالتاجي/الثلاثي. أبهر طبيعي القطر. لا انصباب تاموري. PASP [ ] ملم زئبق.»

٩. البطين الأيسر

  • ضخامة مركزية: «ضخامة مركزية للبطين الأيسر (سماكة الحاجز [ ] ملم، RWT [ ])، كتلة مفهرسة [ ] غ/م².»
  • توسع مع ضعف شامل: «بطين أيسر متوسع (LVIDd [ ] سم) مع نقص تقلص عام [خفيف/متوسط/شديد] (EF [ ]% بطريقة Simpson).»
  • اضطراب موضعي: «لاحركية بالجدار [ ] (القطع: [ ]) بما يتفق مع احتشاء بمنطقة [LAD/RCA/LCx]، مع نقص حركية بالجدار [ ]. EF [ ]%.»
  • خثرة: «كتلة [ ] × [ ] ملم بقمة البطين الأيسر مجاورة للجدار اللاحركي، تتفق مع خثرة (تُرى بمنظرين).»
  • انبساط: «خلل وظيفي انبساطي [من الدرجة I/II/III] مع مؤشرات ارتفاع ضغط الامتلاء (E/e′ [ ]، LAVI [ ]).»

١٠. الدسامات

  • تضيّق أبهري: «دسام أبهري [ثلاثي/ثنائي] الشرف، [سماكة وتكلس]؛ سرعة الذروة [ ] م/ث، ممال [أعظمي/وسطي] [ ]/[ ] ملم زئبق، AVA [ ] سم² (مفهرسة [ ])، DVI [ ]: تضيّق أبهري [خفيف/متوسط/شديد].»
  • قصور أبهري: «قصور أبهري [خفيف/متوسط/شديد]، النفاثة [مركزية/لامركزية]، vena contracta [ ] ملم، PHT [ ] م ث، [مع/بدون] انعكاس انبساطي بالأبهر النازل.»
  • تضيّق تاجي: «تضيّق تاجي رثوي: تقبّب الوريقة الأمامية وسماكة بالوريقات والأوتار؛ ممال وسطي [ ] ملم زئبق عند معدل قلب [ ]، PHT [ ] م ث، MVA [ ] سم²؛ Wilkins [ ]. الأذين الأيسر [متوسع]؛ [لا خثرة ظاهرة].»
  • قلس تاجي: «قلس تاجي [خفيف/متوسط/شديد] بآلية [تدلٍّ/انفلات/وظيفي/رثوي]، vena contracta [ ] ملم، EROA [ ] ملم²، RVol [ ] مل، [انعكاس انقباضي بالوريد الرئوي].»
  • قلس ثلاثي: «قلس ثلاثي [ ] بآلية [ثانوية لتوسع الحلقة/أولية]، حلقة [ ] ملم، PASP [ ] ملم زئبق.»
  • دسام صنعي: «دسام [نوع] بالوضع [ ]، حركة [طبيعية/محدودة]، سرعة [ ] م/ث، ممال وسطي [ ] ملم زئبق، DVI [ ]؛ [لا قلس حول الدسام / قلس حول الدسام بمقدار [ ]].»

١١. التامور والبطين الأيمن والضغوط

  • انصباب تاموري: «انصباب تاموري [صغير/متوسط/كبير] ([ ] ملم)، [شامل/موضعي]، [بدون/مع] علامات سطام (انهيار الأذين/البطين الأيمن، IVC متسع).»
  • البطين الأيمن: «بطين أيمن [متوسع/طبيعي]، وظيفة [طبيعية/منخفضة] (TAPSE [ ] ملم، S′ [ ] سم/ث).»
  • فرط توتر رئوي: «سرعة قلس الثلاثي [ ] م/ث، PASP تقديري [ ] ملم زئبق (RAP [ ])، [بالإضافة إلى علامات: تسطّح الحاجز، توسع الأذين الأيمن] ـ احتمال فرط توتر رئوي [منخفض/متوسط/مرتفع].»

١٢. الأبهر والكتل والأجهزة

  • توسع الأبهر: «الجيوب [ ] ملم، الوصل الجيبي الأنبوبي [ ] ملم، الأبهر الصاعد [ ] ملم (Z-score [ ])؛ [مقارنة بفحص سابق: ثابت/زيادة [ ] ملم].»
  • كتلة: «كتلة [ ] × [ ] ملم بـ[الموضع]، [ذات ساق/عريضة القاعدة]، [متحركة/ثابتة]، بكثافة [ ]، [بدون/مع] أثر هيموديناميكي؛ يُنصح بـ[TOE/CMR].»
  • ASD/PFO: «ثقب [ثانوي] بالحاجز بين الأذينين [ ] ملم، حواف [كافية/ناقصة]، تحويلة [يسار–يمين]، Qp:Qs [ ]، توسع القلب الأيمن [ ]، PASP [ ].»
  • جهاز: «سلك [ ] بالأذين/البطين الأيمن، [لا كتل ظاهرة عليه]، [قلس ثلاثي مرافق].»

١٣. كتابة الخلاصة (Impression)

  • ابدأ بالنتيجة الأهم سريرياً وليس بترتيب التشريح.
  • عدد محدود من النقاط (3–6)، كل نقطة بجملة وبرقم عند اللزوم.
  • اربط النتائج بالسؤال السريري: «لا دليل على…»، «يتفق مع…»، «لا يمكن استبعاد…».
  • اذكر التغيّر عن الفحص السابق إن وُجد.

١٤. التوصيات

  • إيكو متابعة بعد [ ] أشهر (بحسب شدة الآفة).
  • TOE لـ[تنبتة/خثرة الأذين/التسرب حول الدسام] عند الشك.
  • CMR/CT لـ[الأبهر/التامور/الندبة].
  • تقييم قلبي تداخلي أو جراحي (فريق القلب) عند تحقق الاستطباب.
  • تصوير الشرايين أو إيكو إجهاد عند اضطراب الحركة الموضعي.

١٥. النتائج الحرجة (تستدعي إبلاغاً فورياً)

النتيجةلماذا؟
سطام تاموري أو انصباب مع تأثير هيموديناميكييحتاج تفريغاً عاجلاً
شريحة تسلخ بالصاعد أو تمدد حادجراحة طارئة
خثرة متحركة بالأذين أو البطين، أو ورم مخاطي معيقخطر انصمام أو انسداد
قلس تاجي أو أبهري حاد شديد، أو تمزق عضلة حليمية أو VSD بعد الاحتشاءجراحة عاجلة وتثبيت الحالة
صمّة رئوية كبيرة مع فشل RVعلاج فوري
أم دم كاذبة بالبطين، تنبتة كبيرة بمضاعفات، خراج جذرتدخل مستعجل
خلل شديد جديد بالـ EF أو تضيّق أبهري شديد عَرَضيتغيّر بالتدبير

يُوثَّق وقت الإبلاغ واسم المستلم بالتقرير.

١٦. نماذج تقارير مختصرة

أ) قصور قلب جديد

«بطين أيسر متوسع (LVIDd [6.3] سم) مع نقص تقلص عام شديد (EF [25]% Simpson). قلس تاجي وظيفي [متوسط]. أذين أيسر متوسع (LAVI [48]). بطين أيمن [طبيعي الوظيفة]. PASP [45] ملم زئبق. لا انصباب تاموري. الخلاصة: اعتلال عضلة توسعي/إقفاري يُنصح بالتقييم الإكليلي. لا خثرة بالقمة.»

ب) بعد احتشاء أمامي

«لاحركية قمية وأمامية ([القطع]) بتروية LAD، EF [35]%. [لا خثرة قمية ظاهرة]، لا قلس تاجي حاد، لا VSD، لا انصباب. الخلاصة: احتشاء أمامي بدرجة [متوسطة]، يُنصح بإيكو متابعة بعد 6–12 أسبوعاً لتقدير EF لقرار ICD.»

ج) تضيّق أبهري شديد قبل الجراحة

«تضيّق أبهري شديد (ذروة [4.6] م/ث، ممال وسطي [52] ملم زئبق، AVA [0.7] سم²، DVI [0.2]). ضخامة مركزية خفيفة، EF [55]%. الخلاصة: تضيّق أبهري شديد يتفق مع الأعراض؛ يُنصح بتقييم فريق القلب.»

د) قبل جراحة غير قلبية

«EF [60]% بلا اضطراب حركة موضعي. لا آفة دسامية ذات دلالة. PASP [28]. الخلاصة: لا مانع قلبي من الإيكو للجراحة المقترحة.»
