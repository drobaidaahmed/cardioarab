⚡ مرجع سريع

💊 الأعمدة الأربعة في HFrEF

  • ARNi: Class I — مفضّل على ACEi
  • Beta-Blocker: Class I — من الأدوية المُثبتة الثلاثة فقط
  • MRA: Class I — مع مراقبة البوتاسيوم/eGFR
  • SGLT2i: Class I — بغضّ النظر عن وجود سكري
  • البدء: متزامن/سريع التتابع، ليس تدريجياً بالضرورة

🧪 HFmrEF وHFpEF

  • SGLT2i: Class IIa في كليهما
  • MRA وARNi: Class IIb في كليهما
  • ضبط الضغط في HFpEF: Class I
  • النترات/PDE5i الروتينية: Class III — لا فائدة

⚡ الأجهزة

  • ICD وقائي: EF≤35% NYHA II–III بعد ≥3 أشهر GDMT
  • CRT: LBBB + QRS≥150ms + EF≤35% — Class I
  • CardioMEMS: NYHA III مع استشفاء سابق — Class IIa/IIb

🛡 الوقاية — المرحلة A/B

  • سكري النوع 2 + خطر قلبي وعائي: SGLT2i للوقاية — Class I
  • ضبط الضغط: حجر الأساس في المرحلة A
  • EF مخفّض بلا أعراض (B): ACEi/BB — Class I

🩺 الأمراض المرافقة

  • نقص الحديد: IV Iron لتحسين الأعراض — Class IIa
  • الرجفان الأذيني في HFpEF: ضبط الإيقاع معقول — Class IIa
  • القصور الكلوي المرافق للسكري: Finerenone — Class I

🏥 المرحلة D — القصور المتقدم

  • الإحالة المبكرة: عند علامات I NEED HELP — Class I
  • LVAD: جسر للزرع أو علاج نهائي حسب الأهلية
  • الزرع القلبي: قيمة اقتصادية متوسطة إلى عالية
