من يحتاج إيكو؟ والنفخات القلبية

سؤال "هل لازم إيكو؟" هو أكثر سؤال بتسمعه بالعيادة. الجواب مش بالإحساس، هو بالأعراض والعلامات وطبيعة النفخة.

١. استطبابات الإيكو العامة

  • أعراض أو علامات يُشتبه بسببها القلب: ضيق نفس، ألم صدر غير مفسّر، غشي، خفقان مع آفة محتملة، وذمة، نفخة مشبوهة.
  • آفات قلبية معروفة: تقييم الشدة والمتابعة (دسامات، قصور قلب، احتشاء، اعتلال عضلة، آفة ولادية).
  • التهاب الشغاف (اشتباه أو تأكيد أو متابعة).
  • مصدر الصمة بعد سكتة أو انصمام (انظر الفصل 18).
  • آفات الأبهر والتامور (انصباب، سطام، التهاب تامور عاصر).
  • تقييم قبل جراحة أو علاج مؤثر بالقلب (أدوية سامة للقلب).
  • فحص أقارب مرضى اعتلالات وراثية.
  • الإيكو لا يُطلب لمجرد "الاطمئنان" أو تكرار فحص طبيعي سابق دون تغيّر سريري.

٢. النفخات القلبية

أسباب النفخة الانقباضية

  • دسامية: تضيق أبهري، تضيق رئوي، قلس تاجي، قلس ثلاثي.
  • غير دسامية: اعتلال ضخامي مع انسداد، فتحة بين البطينين (VSD)، تضيق برزخ الأبهر.
  • تدفق متزايد (نفخة وظيفية): الحمل، فقر الدم، فرط الدرق، الحمى، الرياضيين، الطفولة.

أسباب النفخة الانبساطية

  • قلس: أبهري (أشيع)، رئوي.
  • تضيق: تاجي (أشيع)، ثلاثي.
  • نفخة أوستن فلينت: نفخة انبساطية قمية بسبب قلس أبهري شديد يضغط الوريقة التاجية الأمامية.
  • نفخة مستمرة: بقاء القناة الشريانية، ناسور شرياني وريدي، وغيره.

متى تكون النفخة "بريئة"؟

النفخة البريئة (وظيفية) شائعة عند الأطفال والشباب، وتتميز بأنها: انقباضية فقط، بشدة منخفضة (≤ 2/6)، قصيرة، بدون ارتجاف، تتغير مع الوضعية والتنفس، بدون أعراض، مع صوت ثانٍ طبيعي وتخطيط طبيعي. وفي الحمل والحمى وفقر الدم تُرى نفخات تدفق وظيفية تختفي بزوال السبب.

علامات ترجّح نفخة مرضية (عضوية)

  • نفخة انبساطية أو مستمرة (دائماً مرضية حتى يثبت العكس).
  • نفخة انقباضية عالية (≥ 3/6) أو مع ارتجاف أو طويلة (شاملة للانقباض).
  • نفخة متأخرة بالانقباض أو مع طقة انقباضية.
  • صوت ثانٍ غير طبيعي (مفرد أو مفترق ثابتاً)، أو أصوات قلبية إضافية.
  • أعراض (ضيق نفس، ذبحة، غشي)، أو علامات قصور قلب، أو تخطيط/صورة صدر شاذة.

خلاصة الجزء

النفخة البريئة
نفخة انقباضية خفيفة قصيرة متغيرة مع الوضعية، بدون أعراض ولا علامات مرضية
نفخة تستوجب إيكو
أي نفخة انبساطية أو مستمرة أو شاملة للانقباض أو عالية الشدة، أو مرافقة لأعراض أو علامات
نفخة أوستن فلينت
نفخة انبساطية قمية ناتجة عن قلس أبهري شديد وليس عن تضيق تاجي حقيقي
