١. قبل زرع LVAD

  • وظيفة وحجم البطين الأيسر: يتحمل الدعم حجماً كبيراً؛ والتقييم لوجود خثرة أو أم دم.
  • وظيفة البطين الأيمن (أهم مؤشر لفشل الدعم): TAPSE وFAC وS′ والإجهاد، وحجم RV، والقلس الثلاثي، وPASP وRAP.
  • القلس الأبهري المتوسط فما فوق يجب علاجه (يعطي دورة مفرغة بالدعم).
  • التضيّق التاجي، PFO/ASD (تحويلة يمين–يسار بعد تفريغ الأيسر)، خثرة بالأذين أو الزائدة، التضيّق الأبهري الشديد (أقل أهمية)، ودسام ميكانيكي (خطر خثرة).

٣. دراسة تغيير السرعة (Ramp study)

  • تُغيَّر سرعة المضخة بخطوات (مثلاً 200 دورة/د كل نحو 2 دقيقة) ويُسجَّل لكل خطوة: LVEDD، فتح الدسام الأبهري، وضع الحاجز، القلس التاجي والأبهري، حجم RV وTR، وسرعة القنية.
  • الاستجابة الطبيعية: يتناقص LVEDD (≈ 5 ملم أو أكثر) ويتحسن القلس التاجي مع زيادة السرعة.
  • عدم الاستجابة (لا يتغير حجم البطين أو الضغوط) يوحي بانسداد/خثرة بالمضخة أو القنية (مع ارتفاع LDH وسرعات القنية).
  • تُستعمل لتحديد السرعة المثلى وعند الأعراض أو الإنذارات.

٤. اختلاطات يكشفها الإيكو

  • الشفط (suction): بطين صغير جداً وحاجز مائل لليسار بسبب فرط السرعة أو نقص الحجم.
  • خثرة مضخة/قنية: سرعات مرتفعة، عدم استجابة للـ ramp، توسع بطين.
  • فشل البطين الأيمن وزيادة القلس الثلاثي.
  • القلس الأبهري المتفاقم بسبب إغلاق الدسام الدائم أو ضغط الجذر.
  • انصباب تاموري/سطام، والتهاب شغاف، وخثرة الأبهر الجذري.

٥. القلب المزروع (Heart transplant)

الطبيعي بعد الزرع

  • توسع أذيني ثنائي بشكل «ثمانية» (figure-of-8) إذا استُعمل الربط الأذيني المزدوج، مع خط الخياطة ظاهراً.
  • قلس ثلاثي خفيف–متوسط شائع، وانصباب تاموري صغير مبكراً.
  • سماكة جدار قد تزيد بخفة (حتى 12–13 ملم) مبكراً ثم تتراجع، وEF محفوظة، ووظيفة انبساطية قد تتغير.
  • حركة حاجزية شاذة (بعد الجراحة) بسماكة طبيعية.

الرفض الحاد

  • ازدياد سماكة الجدران/الكتلة وتبدّل شكل (وذمة)، وخلل انبساطي (نمط حاصر وقصر IVRT/DT)، وانصباب تاموري جديد، وأخيراً EF منخفضة.
  • التشخيص بالخزعة؛ والإيكو أداة متابعة تكميلية لا بديلة.

تصلب الأوعية الإكليلية للطعم (CAV)

  • قلب مزروع ينقصه الإحساس بالألم (فلا ذبحة)؛ يُراقَب بإيكو الإجهاد (حركة جدارية موضعية) وGLS، وتصوير الأوعية أو IVUS.
  • تدهور EF أو ضعف إجهاد طولي مبكراً يستدعي التقييم.

RV والدسامات

وظيفة البطين الأيمن، قلس الثلاثي (خاصة مع القثطرة للخزعة)، فرط التوتر الرئوي، ومراقبة الدسامات.
