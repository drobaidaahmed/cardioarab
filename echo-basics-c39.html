الإيكو حسب الأعراض والمؤشرات

١. استطبابات الإيكو العامة

  • أعراض أو علامات يُشتبه بسببها القلب: ضيق نفس، ألم صدر غير مفسّر، غشي، خفقان مع آفة محتملة، وذمة، نفخة مشبوهة.
  • آفات قلبية معروفة: تقييم الشدة والمتابعة (دسامات، قصور قلب، احتشاء، اعتلال عضلة، آفة ولادية).
  • التهاب الشغاف (اشتباه أو تأكيد أو متابعة).
  • مصدر الصمة بعد سكتة أو انصمام (انظر الأقسام الأخرى من هذا الفصل).
  • آفات الأبهر والتامور (انصباب، سطام، التهاب تامور عاصر).
  • تقييم قبل جراحة أو علاج مؤثر بالقلب (أدوية سامة للقلب).
  • فحص أقارب مرضى اعتلالات وراثية.
  • الإيكو لا يُطلب لمجرد "الاطمئنان" أو تكرار فحص طبيعي سابق دون تغيّر سريري.

٢. النفخات القلبية

أسباب النفخة الانقباضية

  • دسامية: تضيق أبهري، تضيق رئوي، قلس تاجي، قلس ثلاثي.
  • غير دسامية: اعتلال ضخامي مع انسداد، فتحة بين البطينين (VSD)، تضيق برزخ الأبهر.
  • تدفق متزايد (نفخة وظيفية): الحمل، فقر الدم، فرط الدرق، الحمى، الرياضيين، الطفولة.

أسباب النفخة الانبساطية

  • قلس: أبهري (أشيع)، رئوي.
  • تضيق: تاجي (أشيع)، ثلاثي.
  • نفخة أوستن فلينت: نفخة انبساطية قمية بسبب قلس أبهري شديد يضغط الوريقة التاجية الأمامية.
  • نفخة مستمرة: بقاء القناة الشريانية، ناسور شرياني وريدي، وغيره.

متى تكون النفخة "بريئة"؟

النفخة البريئة (وظيفية) شائعة عند الأطفال والشباب، وتتميز بأنها: انقباضية فقط، بشدة منخفضة (≤ 2/6)، قصيرة، بدون ارتجاف، تتغير مع الوضعية والتنفس، بدون أعراض، مع صوت ثانٍ طبيعي وتخطيط طبيعي. وفي الحمل والحمى وفقر الدم تُرى نفخات تدفق وظيفية تختفي بزوال السبب.

علامات ترجّح نفخة مرضية (عضوية)

  • نفخة انبساطية أو مستمرة (دائماً مرضية حتى يثبت العكس).
  • نفخة انقباضية عالية (≥ 3/6) أو مع ارتجاف أو طويلة (شاملة للانقباض).
  • نفخة متأخرة بالانقباض أو مع طقة انقباضية.
  • صوت ثانٍ غير طبيعي (مفرد أو مفترق ثابتاً)، أو أصوات قلبية إضافية.

من لديه نفخة ويحتاج إيكو؟

٣. السكتة الدماغية وTIA والانصمام الجهازي

السؤال: "هل يوجد مصدر قلبي للصمة؟" المصادر القلبية الرئيسية:

  • خثرة البطين الأيسر (بعد احتشاء أمامي، اعتلال عضلة توسعي، أم دم بطينية).
  • تنبتات التهاب الشغاف الجرثومي أو غير الجرثومي (الصمامات الصنعية، التنبتات العقيمة).
  • الورم المخاطي وأورام أخرى (الورم الليفي المرن الحليمي).
  • الثقبة البيضوية المفتوحة (PFO) وأم دم الحاجز بين الأذينين، مع احتمال انصمام متناقض.
  • عصيدة الأبهر القوسية (سماكة > 4 ملم أو متحركة).
  • صمامات: تكلس الحلقة التاجية أو الأبهري، خيوط لامبل.

الإيكو ليس الاختبار الوحيد: يفيد دوبلر الشريان السباتي، وتضيق سباتي > 70% استطباب لاستئصال باطنة السباتي. وعند مريض بتاريخ وفحص وتخطيط طبيعيين يكون احتمال أن يكشف TTE آفة قلبية منخفضاً جداً. الغرض الأساسي: تشخيص حالة ترفع خطر الانصمام (كالتضيق التاجي أو توسع البطين)، أو كشف مصدر مباشر (خثرة أو ورم أو تنبتة).

متى يُطلب الإيكو؟

  • انسداد مفاجئ بشريان طرفي أو حشوي.
  • سكتة أو TIA عند عمر < 50 سنة، أو بعد الخمسين بدون مرض دماغي وعائي أو سبب واضح آخر.
  • اشتباه مرض انصمامي، أو علامة قلبية بالفحص (نفخة، اشتباه التهاب شغاف) أو تخطيط شاذ (احتشاء، رجفان، VT، اضطراب ST-T).

إذا وُجد التضيق التاجي (خاصة مع رجفان) ترتفع مخاطر الانصمام جداً بحيث يُنظر بالتمييع حتى لو لم تُرَ خثرة (فخثرة الأذين الأيسر غالباً لا تُرى بـ TTE) بعد استبعاد النزف بالتصوير المقطعي؛ وقد تُرى خثرة كروية كبيرة وهي استطباب لجراحة عاجلة. وعند الشباب يُجرى TTE وTOE للبحث عن أسباب نادرة: ورم مخاطي (نحو 1% من الحالات)، وSEC، وخثرة الزائدة، وPFO، وأم دم الحاجز بين الأذينين، وعصيدة الأبهر.

تفصيل الاستطبابات والـ TOE

يُنصح بـ TTE عند معظم مرضى السكتة الإقفارية أو TIA عندما لا يوجد سبب واضح، خصوصاً عند الأعمار الشابة أو وجود سوابق قلبية أو علامات فحص قلبي. ويُطلب TOE (مع TTE طبيعي أو غير حاسم) عندما:

  • يوجد شك قوي بمصدر قلبي (سكتة غير مفسّرة عند عمر < 50 أو بعدة أماكن).
  • المريض مرشح لعلاج يتغير بنتيجته (كإغلاق PFO أو علاج مضاد للتخثر).
  • الاشتباه بالتهاب شغاف أو بأمراض الأبهر الصاعد والقوس.

٤. ضيق النفس والوذمة المحيطية

ضيق النفس عَرَض مشترك لأمراض قلبية ورئوية وغيرها. الإيكو يحدد إن كان للقلب دور، عبر البحث عن:

  • خلل وظيفة انقباضية أو انبساطية بالبطين الأيسر (أحياناً EF محفوظ مع ارتفاع ضغوط الامتلاء: HFpEF).
  • آفة صمامية شديدة (تضيق أو قلس).
  • ارتفاع ضغط الشريان الرئوي وخلل البطين الأيمن (مرض رئوي، صمّة رئوية مزمنة).
  • انصباب تاموري أو التهاب تامور عاصر.
  • اعتلالات العضلة (ضخامي، حاصر).

إذا كان JVP طبيعياً فالإيكو غير مرجح الفائدة (إلا لمن يتلقى مدرات). وتشمل الأسباب غير القلبية: الفشل الكلوي، فقد البروتين (المتلازمة الكلائية)، نقص الألبومين (الكبد)، خثار الأوردة العميقة، قصور الأوردة، انسداد الحوض، قصور الدرق.

الوذمة المحيطية لها أسباب قلبية (قصور القلب الأيمن، التهاب التامور العاصر، فرط التوتر الرئوي الشديد، قلس ثلاثي الشرف شديد) وأسباب غير قلبية (كبدية، كلوية، وريدية، دوائية). لذلك يُطلب الإيكو إذا وُجدت علامات قلبية (توسع الوداجي، نفخة، ضيق نفس)، أو عندما تكون الوذمة غير مفسّرة، وتُلاحظ فيه: ضغط الأذين الأيمن (IVC)، وحجم البطين الأيمن ووظيفته، والقلس الثلاثي، وانصباب التامور.

٥. الفحص المسحي (Screening)

استطبابات جيدة

  • أقارب الدرجة الأولى لمريض اعتلال عضلة ضخامي أو توسعي عائلي.
  • أقارب مرضى تشوه أبهري عائلي أو متلازمة مارفان (قياس الجذر).
  • مرضى يتلقون علاجاً سام للقلب (بعض أدوية الأورام) قبل بدء العلاج وأثناءه.
  • قبل الجراحات الكبرى عند مرضى عندهم عوامل خطر قلبية أو نفخة أو أعراض.
  • الحمل عند سيدات لديهن آفة قلبية معروفة (انظر الفصل 40).

شروط الفحص المسحي: أن يكون الفحص آمناً ودقيقاً ومتاحاً ورخيصاً (والإيكو كذلك)، وأن يكون الشذوذ كثيراً بما يكفي، وأن يغيّر الكشف التدبير أو يعطي معلومة مآلية.

  • أقارب الدرجة الأولى لمرضى HCM: يُفحص كثيرون كل 5 سنوات من عمر 5 حتى 20؛ ونحو واحد من كل خمسة أقارب مصاب بالفعل بدراسة مسحية كبيرة، وإن كان الإيكو طبيعياً عند 20 يُستبعد التشخيص عادة.
  • الاشتباه بشذوذ نسيج ضام (مارفان وإهلرز–دانلوس) مع تصحيح للحجم والعمر، وأقارب مرضى الورم المخاطي العائلي أو التصلب الدرني.
  • مانحو القلب المحتملون بالعناية المركزة: نحو 1 من 4 يظهر عنده ما يستبعد التبرع.
  • خط أساس ومتابعة عند العلاج الكيماوي السام للقلب (الدوكسوروبيسين: الجرعة التراكمية < 450–500 ملغ/م²).

استطبابات أقل وضوحاً

  • مرضى ارتفاع الضغط بدون أعراض ولا سوابق قلبية ولا علامات.
  • أصحاب نفخة وظيفية واضحة بدون أعراض ولا علامات مرضية.
  • فحص روتيني للأصحاء بدون سؤال سريري.

٦. إيكو المتابعة (Follow-up)

الإيكو الكامل المتكرر دون تغيّر بالحالة السريرية قليل الفائدة. يُتابَع المرضى بفواصل زمنية تقريبية حسب الآفة وشدتها:

الحالةفاصل المتابعة التقريبي
تضيق أبهري أو تاجي شديد غير معالج بلا أعراضكل 6–12 شهراً
تضيق أو قلس متوسطكل 1–2 سنة
قلس خفيف بقلب سليملا يحتاج متابعة روتينية
توسع الأبهر الصاعدحسب القطر؛ يقصر الفاصل كلما كبر القطر أو زاد معدل النمو
قصور قلبعند تغيّر الحالة السريرية أو بعد تعديل علاج مهم أو بعد 3 أشهر من علاج أمثل لتقرير ICD
دسام صنعيإيكو أساسي بعد الزرع بشهرين–ثلاثة، ثم عند ظهور أعراض أو تغيّر النفخة أو الشك بالدسام

الفواصل التقليدية: تضيق أبهري شديد كل 3–6 أشهر ومتوسط سنوياً؛ قلس أبهري متوسط كل 3–6 أشهر؛ اعتلال ضخامي سنوياً؛ جذر أبهر متوسع كل 6–12 شهراً؛ مرض التاجي سنوياً؛ دسامات حيوية صنعية بعد 5 سنوات ثم سنوياً؛ ضعف البطين حسب الأعراض؛ بعد استئصال ورم قلبي سنوياً حتى 5 سنوات.

ملاحظة: الفواصل أعلاه إرشادية تقريبية وتختلف بحسب إرشادات الدسامات المعتمدة (ESC/AHA)؛ يُقرّرها الطبيب حسب الحالة.
